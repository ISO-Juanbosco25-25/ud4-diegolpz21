# 🔴 ERROR 1

📌 Descripción:
Poca pasta termica colocada en el disipador

📌 Tipo:
Real

📌 Fase del montaje:
Instalación del disipador en la CPU

📌 Causa:
Ocurrio debido a que nunca habia puesto pasta termica y no tenia como guiarme y por eso puse muy poca

📌 Consecuencia:
Sobrecalentamiento

📌 Solución aplicada o propuesta:
Desmontando el disipador y poniendo mas pasta

📌 ¿Cómo prevenirlo?
Para solucionar este error tendria que ver referencias y poner mas la proxima vez

# 🔴 ERROR 2

📌 Descripción:
Dificultad a la hora de montar el ventilador del chasis

📌 Tipo:
Real

📌 Fase del montaje:
Montaje del ventilador del chasis

📌 Causa:
Poca experiencia montando PCs

📌 Consecuencia:
No tiene consecuencias como tal si lo consigues poner, pero puede quedar mal puesto, o puedes romper algo si aprietas mucho

📌 Solución:
Desmontarlo y volver a montarlo tranquilamente hasta que quede bien

📌 Prevención:
Estudiando mas las partes y practicas mas poniendo ventiladores

📸 Evidencia:
https://www.youtube.com/watch?v=UvyuJm6-Zpk Minutos: 13:02-18:00
